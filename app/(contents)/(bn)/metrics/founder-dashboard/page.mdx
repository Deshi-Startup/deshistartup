# মাসিক ফাউন্ডার ড্যাশবোর্ড

> **সারকথা:** এই পেজে একটা টেবিল আছে, মাসে একবার বসে ভরার মতো। ব্যাংকে কত ক্যাশ আছে, কন্ট্রিবিউশন মার্জিন কোন দিকে যাচ্ছে, CAC কত, রানওয়ে (ক্যাশ ফুরাতে আর কত মাস বাকি) কত আর আসল মুনাফা-লোকসান কত, এই কয়েকটা নম্বর পাশাপাশি রাখলেই বোঝা যায় ব্যবসা কোন দিকে যাচ্ছে। এটা মাসের আর্থিক পর্যালোচনা। প্রতিদিন বা প্রতি সপ্তাহে অর্ডার, ডেলিভারি রেট, স্টকের মতো অপারেশনাল সংখ্যা দেখার জন্য আলাদা [সাপ্তাহিক অপারেশনস ড্যাশবোর্ড](/metrics/ops-dashboard) আছে, টিম বড় হলে সেটা কাজে লাগে। দুটো এক জিনিস না, একটা মাসে একবার ব্যাংক ব্যালেন্স আর রানওয়ে দেখার জন্য, অন্যটা সপ্তাহে সপ্তাহে অপারেশন সামলানোর জন্য।

## মাসিক ড্যাশবোর্ড টেমপ্লেট

গুগল শিটে এই টেবিলটা বসান। প্রতি মাসের শেষে বা পরের মাসের শুরুতে এক বসায় সংখ্যাগুলো ভরুন।

| মেট্রিক | এই মাস | গত মাস | টার্গেট / অ্যালার্ট |
|---|---|---|---|
| মোট বিক্রি (রাজস্ব) |  |  | ট্রেন্ড দেখুন, একটানা কমলে সতর্ক হোন |
| তালিকাভুক্ত খরচের পর উদ্বৃত্ত/ঘাটতি |  |  | পরপর দুই মাস লোকসান হলে খরচ ঘেঁটে দেখুন |
| কন্ট্রিবিউশন মার্জিন (গড়, অর্ডার বা কাস্টমারপ্রতি) |  |  | ঋণাত্মক হলে লাল অ্যালার্ট, দেখুন [ইউনিট ইকোনমিক্স](/metrics/unit-economics) |
| CAC (একজন নতুন কাস্টমার পাওয়ার খরচ) |  |  | কন্ট্রিবিউশনের তুলনায় বেড়ে গেলে বুস্ট থামান |
| LTV:CAC অনুপাত |  |  | ৩ গুণের নিচে নামলে সতর্ক, দেখুন [CAC, LTV, চার্ন](/metrics/cac-ltv-churn) |
| অ্যাকটিভ বা রিপিট কাস্টমার সংখ্যা |  |  | মাসে মাসে কমলে সতর্ক |
| চার্ন বা রিটেনশন হার |  |  | চার্ন বাড়লে লাল, দেখুন [CAC, LTV, চার্ন](/metrics/cac-ltv-churn) |
| ব্যাংকে থাকা ক্যাশ |  |  | শূন্যের কতটা কাছে, সেটাই আসল সংকেত |
| মাসিক নিট বার্ন (পরিচালনায় ক্যাশ খরচ বিয়োগ ক্যাশ আদায়) |  |  | ফান্ডিং বাদ দিন। টাকা আসার সময় ও সামনে থাকা দায় দেখুন |
| রানওয়ে (মাস) |  |  | ৬ মাসের নিচে নামলে লাল অ্যালার্ট |

"এই মাস" আর "গত মাস" কলাম পাশাপাশি রাখাই আসল কাজ। একলা এক মাসের সংখ্যা বেশি কিছু বলে না, প্রবণতাই বলে দেয় ব্যবসা ভালোর দিকে না খারাপের দিকে যাচ্ছে।

## রাহিমের ড্যাশবোর্ড: একটা মাস ভরে দেখুন

[ইউনিট ইকোনমিক্সে](/metrics/unit-economics) রাহিমের যে হিসাব দেখানো হয়েছে, সেটা এই টেবিলে বসালে এমন দেখাবে। রাহিম মাসে ১০ হাজার টাকা বুস্ট করে ১২৫টা অর্ডার পান, প্রতি অর্ডারে অ্যাডের খরচ ৮০ টাকা। এটি কাস্টমারপ্রতি CAC নয়। এক অর্ডারে কাগজে-কলমে কন্ট্রিবিউশন ১৬০ টাকা, কিন্তু ফেরত অর্ডার (RTO) ধরলে বাস্তব সংখ্যা নেমে আসে। ফিক্সড খরচ, নিজের হাতখরচ, ফোন-ইন্টারনেট আর টুকটাক খরচ মিলিয়ে, মাসে ১১ হাজার ৫০০ টাকা। এই সরল উদাহরণে সব বিক্রি ও খরচের টাকা একই মাসে মিটেছে, ফেরত পণ্য আবার বিক্রি করা যাবে এবং অন্য কোনো ক্যাশ লেনদেন বা বকেয়া নেই বলে ধরা হয়েছে। নিজের হাতখরচ এখানে পরিকল্পনার খরচ, করের শ্রেণিবিন্যাস নয়।

| মেট্রিক | এই মাস | গত মাস |
|---|---|---|
| মোট বিক্রি (রাজস্ব) | ১ লাখ ২০ হাজার টাকা (১০০টা অর্ডার ডেলিভার হয়েছে) | প্রায় ১ লাখ ১৩ হাজার টাকা (৯৪টা অর্ডার ডেলিভার হয়েছে) |
| তালিকাভুক্ত খরচের পর উদ্বৃত্ত/ঘাটতি | -৩ হাজার টাকা | -৫ হাজার ৭৬০ টাকা |
| কন্ট্রিবিউশন মার্জিন (গড়/অর্ডার, ফেরতসহ) | ৬৮ টাকা | প্রায় ৪৬ টাকা |
| পাঠানো অর্ডারপ্রতি অ্যাডের খরচ | ৮০ টাকা | ৮০ টাকা |
| LTV:CAC অনুপাত | প্রযোজ্য নয় (একবার-বেচা ব্যবসা) | প্রযোজ্য নয় |
| পাঠানো অর্ডার (আলাদা কাস্টমার নয়) | ১২৫ অর্ডার | ১২৫ অর্ডার |
| ফেরত হার (RTO) | ২৫ / ১২৫ = ২০% | ৩১ / ১২৫ = ২৪.৮% |
| ব্যাংকে থাকা ক্যাশ | ২১ হাজার টাকা | ২৪ হাজার টাকা |
| মাসিক বার্ন (নিট) | ৩ হাজার টাকা | ৫ হাজার ৭৬০ টাকা |
| রানওয়ে | ৭ মাস | প্রায় ৪.২ মাস |

সংখ্যাগুলো একসঙ্গে পড়লে গল্পটা পরিষ্কার হয়ে যায়। বিক্রি গত মাসের তুলনায় সামান্যই বেড়েছে, অথচ লোকসান প্রায় অর্ধেক নেমেছে আর রানওয়ে প্রায় দ্বিগুণ হয়েছে। কারণ একটাই, ফেরত অর্ডারের হার ৪টায় ১ থেকে কমে ৫টায় ১ হয়েছে। শুধু বিক্রির সংখ্যা দেখলে এই উন্নতি ধরাই পড়ত না, ধরা পড়ল কন্ট্রিবিউশন আর বার্নের সারিতে।

রাহিমের ব্যবসা এক অর্ডার-ভিত্তিক বলে LTV:CAC অনুপাত আর চার্নের ঘর তাঁর বেলায় প্রযোজ্য না। বারবার-বেচা বা সাবস্ক্রিপশন ব্যবসা হলে এই দুই ঘর ভরাই জরুরি, বিস্তারিত হিসাব [CAC, LTV, চার্ন পেজে](/metrics/cac-ltv-churn) আছে। নিজের ব্যবসায় যে ঘর খাটে না, সেখানে জোর করে সংখ্যা না বসিয়ে সরাসরি "প্রযোজ্য নয়" লিখুন।

## রানওয়ে যেভাবে বের করবেন

এই টেবিলের একটাই নম্বর নিজে হাতে গভীরভাবে শেখার মতো, বাকিগুলোর হিসাব অন্য পেজে আছে। নম্বরটা হলো রানওয়ে (runway), মানে এখনকার গতিতে খরচ চললে ব্যাংকের টাকায় আর কত মাস চলবে।

হিসাবটা এক লাইনের:

**রানওয়ে = ব্যাংকে থাকা ক্যাশ ÷ মাসিক বার্ন**

মাসিক নিট বার্ন হলো ব্যবসা চালাতে দেওয়া ক্যাশ থেকে পরিচালনার মাধ্যমে আদায় হওয়া ক্যাশ বাদ দিলে যা থাকে। বিনিয়োগ বা ঋণের টাকা এখানে ধরবেন না। স্টক, ক্রেতার টাকা ও সাপ্লায়ারের বিল ভিন্ন সময়ে মিটলে লাভের সঙ্গে বার্ন মিলবে না। এই উদাহরণে সব টাকা একই মাসে মিটেছে বলেই বাঁধা খরচ থেকে কন্ট্রিবিউশন বাদ দিয়ে বার্ন পাওয়া যাচ্ছে। রাহিমের এই মাসের হিসাবে ফিক্সড খরচ ১১ হাজার ৫০০ টাকা, মোট কন্ট্রিবিউশন ৮ হাজার ৫০০ টাকা, তাই বার্ন দাঁড়ায় ৩ হাজার টাকা। ব্যাংকে আছে ২১ হাজার টাকা। রানওয়ে বের করতে ২১ হাজার টাকাকে ৩ হাজার টাকা দিয়ে ভাগ করুন, ফল দাঁড়ায় ৭ মাস।

এর মানে, আজ থেকে হিসাব একদম না বদলালে সাত মাস পর ব্যাংকে টাকা শেষ। বাস্তবে হিসাব প্রতি মাসেই একটু বদলায়, তাই রানওয়ে প্রতি মাসে নতুন করে বের করতে হয়, একবার হিসাব করে ভুলে থাকলে চলবে না।

করণীয় সোজা। রানওয়ে ৬ মাসের নিচে নামলে বা টানা কমতে থাকলে তিনটা রাস্তা খোলা থাকে, খরচ কমান, কন্ট্রিবিউশন বাড়ান ([ইউনিট ইকোনমিক্সের](/metrics/unit-economics) ব্রেক-ইভেন অংশ দেখুন), অথবা বাইরে থেকে টাকা আনার পরিকল্পনা এখনই শুরু করুন। সংখ্যাটা শূন্যের কাছে যাওয়ার অপেক্ষা করবেন না, তত দিনে সিদ্ধান্ত নেওয়ার সময় থাকে না।

নিট বার্ন শূন্য বা ঋণাত্মক হলে এই ভাগ দিয়ে অর্থপূর্ণ রানওয়ে পাওয়া যায় না। সে ক্ষেত্রে লিখুন, বর্তমান বার্নে প্রযোজ্য নয়। সপ্তাহ ধরে ক্যাশের পূর্বাভাস করুন। কর, ঋণ শোধ, স্টক কেনা ও অন্য দায় মেটাতে ক্যাশ কমতে পারে। এক মাস লাভ হলেই ব্যাংকের টাকা বাড়বে, এমন নয়।

## কবে বসে করবেন

মাসের একটা নির্দিষ্ট দিন বেছে নিন, যেমন প্রতি মাসের ১ তারিখ বা ব্যাংক স্টেটমেন্ট হাতে আসার পরের দিন, আর প্রতি মাসে সেই একই দিনে বসুন। একই দিনে করলে এক মাসের সংখ্যা আরেক মাসের সঙ্গে সত্যিই মেলানো যায়, এলোমেলো দিনে করলে তুলনাটাই মিথ্যা হয়ে যায়।

সাপ্তাহিক অর্ডার আর খরচের হিসাব আগে থেকে টুকে রাখা থাকলে এই টেবিল ভরতে ৩০-৪৫ মিনিটের বেশি লাগার কথা না। প্রথমবার শেষ কয়েক মাসের অর্ডার আর ব্যাংক স্টেটমেন্ট ঘেঁটে বসাতে ঘণ্টাখানেক লাগতে পারে, তারপরের মাসগুলো অনেক দ্রুত হয়ে যায়।
