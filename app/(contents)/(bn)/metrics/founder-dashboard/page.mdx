# মাসিক ফাউন্ডার ড্যাশবোর্ড

> **সারকথা:** এই পাতায় একটা টেবিল আছে, মাসে একবার বসে ভরার মতো। ব্যাংকে কত ক্যাশ আছে, কন্ট্রিবিউশন মার্জিন কোন দিকে যাচ্ছে, CAC কত, রানওয়ে (ক্যাশ ফুরাতে আর কত মাস বাকি) কত আর আসল মুনাফা-লোকসান কত, এই কয়েকটা নম্বর পাশাপাশি রাখলেই বোঝা যায় ব্যবসা কোন দিকে যাচ্ছে। এটা মাসের আর্থিক পর্যালোচনা। প্রতিদিন বা প্রতি সপ্তাহে অর্ডার, ডেলিভারি রেট, স্টকের মতো অপারেশনাল সংখ্যা দেখার জন্য আলাদা [সাপ্তাহিক অপারেশনস ড্যাশবোর্ড](/metrics/ops-dashboard) আছে, টিম বড় হলে সেটা কাজে লাগে। দুটো এক জিনিস না, একটা মাসে একবার ব্যাংক ব্যালেন্স আর রানওয়ে দেখার জন্য, অন্যটা সপ্তাহে সপ্তাহে অপারেশন সামলানোর জন্য।

## মাসিক ড্যাশবোর্ড টেমপ্লেট

গুগল শিটে এই টেবিলটা বসান। প্রতি মাসের শেষে বা পরের মাসের শুরুতে এক বসায় সংখ্যাগুলো ভরুন।

| মেট্রিক | এই মাস | গত মাস | টার্গেট / অ্যালার্ট |
|---|---|---|---|
| মোট বিক্রি (রাজস্ব) |  |  | ট্রেন্ড দেখুন, একটানা কমলে সতর্ক হোন |
| নিট মুনাফা/লোকসান |  |  | পরপর দুই মাস লোকসান হলে খরচ ঘেঁটে দেখুন |
| কন্ট্রিবিউশন মার্জিন (গড়, অর্ডার বা কাস্টমারপ্রতি) |  |  | ঋণাত্মক হলে লাল অ্যালার্ট, দেখুন [ইউনিট ইকোনমিক্স](/metrics/unit-economics) |
| CAC (এক কাস্টমার বা অর্ডার আনার খরচ) |  |  | কন্ট্রিবিউশনের তুলনায় বেড়ে গেলে বুস্ট থামান |
| LTV:CAC অনুপাত |  |  | ৩ গুণের নিচে নামলে সতর্ক, দেখুন [CAC, LTV, চার্ন](/metrics/cac-ltv-churn) |
| অ্যাকটিভ বা রিপিট কাস্টমার সংখ্যা |  |  | মাসে মাসে কমলে সতর্ক |
| চার্ন বা রিটেনশন হার |  |  | চার্ন বাড়লে লাল, দেখুন [CAC, LTV, চার্ন](/metrics/cac-ltv-churn) |
| ব্যাংকে থাকা ক্যাশ |  |  | শূন্যের কতটা কাছে, সেটাই আসল সংকেত |
| মাসিক বার্ন (নিট, ফিক্সড খরচ বিয়োগ কন্ট্রিবিউশন) |  |  | কন্ট্রিবিউশন ফিক্সড খরচ ছাড়ালে বার্ন থেমে যায় |
| রানওয়ে (মাস) |  |  | ৬ মাসের নিচে নামলে লাল অ্যালার্ট |

"এই মাস" আর "গত মাস" কলাম পাশাপাশি রাখাই আসল কাজ। একলা এক মাসের সংখ্যা বেশি কিছু বলে না, প্রবণতাই বলে দেয় ব্যবসা ভালোর দিকে না খারাপের দিকে যাচ্ছে।

## রাহিমের ড্যাশবোর্ড: একটা মাস ভরে দেখুন

[ইউনিট ইকোনমিক্সে](/metrics/unit-economics) রাহিমের যে হিসাব দেখানো হয়েছে, সেটা এই টেবিলে বসালে এমন দেখাবে। রাহিম মাসে ১০ হাজার টাকা বুস্ট করে ১২৫টা অর্ডার পান, প্রতি অর্ডারে CAC ৮০ টাকা। এক অর্ডারে কাগজে-কলমে কন্ট্রিবিউশন ১৬০ টাকা, কিন্তু ফেরত অর্ডার (RTO) ধরলে বাস্তব সংখ্যা নেমে আসে। ফিক্সড খরচ, নিজের হাতখরচ, ফোন-ইন্টারনেট আর টুকটাক খরচ মিলিয়ে, মাসে ১১ হাজার ৫০০ টাকা।

| মেট্রিক | এই মাস | গত মাস |
|---|---|---|
| মোট বিক্রি (রাজস্ব) | ১ লাখ ২০ হাজার টাকা (১০০টা অর্ডার ডেলিভার হয়েছে) | প্রায় ১ লাখ ১৩ হাজার টাকা (৯৪টা অর্ডার ডেলিভার হয়েছে) |
| নিট মুনাফা/লোকসান | -৩ হাজার টাকা | -৬ হাজার টাকা |
| কন্ট্রিবিউশন মার্জিন (গড়/অর্ডার, ফেরতসহ) | ৬৮ টাকা | ৪৪ টাকা |
| CAC (অর্ডারপ্রতি বুস্ট খরচ) | ৮০ টাকা | ৮০ টাকা |
| LTV:CAC অনুপাত | প্রযোজ্য নয় (একবার-বেচা ব্যবসা) | প্রযোজ্য নয় |
| অ্যাকটিভ কাস্টমার (অর্ডার সংখ্যা/মাস দিয়ে ট্র্যাক) | ১২৫ অর্ডার | ১২৫ অর্ডার |
| ফেরত অর্ডারের হার (RTO) | ৫টায় ১টা | ৪টায় ১টা |
| ব্যাংকে থাকা ক্যাশ | ২১ হাজার টাকা | ২৪ হাজার টাকা |
| মাসিক বার্ন (নিট) | ৩ হাজার টাকা | ৬ হাজার টাকা |
| রানওয়ে | ৭ মাস | ৪ মাস |

সংখ্যাগুলো একসঙ্গে পড়লে গল্পটা পরিষ্কার হয়ে যায়। বিক্রি গত মাসের তুলনায় সামান্যই বেড়েছে, অথচ লোকসান প্রায় অর্ধেক নেমেছে আর রানওয়ে প্রায় দ্বিগুণ হয়েছে। কারণ একটাই, ফেরত অর্ডারের হার ৪টায় ১ থেকে কমে ৫টায় ১ হয়েছে। শুধু বিক্রির সংখ্যা দেখলে এই উন্নতি ধরাই পড়ত না, ধরা পড়ল কন্ট্রিবিউশন আর বার্নের সারিতে।

রাহিমের ব্যবসা এক অর্ডার-ভিত্তিক বলে LTV:CAC অনুপাত আর চার্নের ঘর তাঁর বেলায় প্রযোজ্য না। বারবার-বেচা বা সাবস্ক্রিপশন ব্যবসা হলে এই দুই ঘর ভরাই জরুরি, বিস্তারিত হিসাব [CAC, LTV, চার্ন পাতায়](/metrics/cac-ltv-churn) আছে। নিজের ব্যবসায় যে ঘর খাটে না, সেখানে জোর করে সংখ্যা না বসিয়ে সরাসরি "প্রযোজ্য নয়" লিখুন।

## রানওয়ে যেভাবে বের করবেন

এই টেবিলের একটাই নম্বর নিজে হাতে গভীরভাবে শেখার মতো, বাকিগুলোর হিসাব অন্য পাতায় আছে। নম্বরটা হলো রানওয়ে (runway), মানে এখনকার গতিতে খরচ চললে ব্যাংকের টাকায় আর কত মাস চলবে।

হিসাবটা এক লাইনের:

**রানওয়ে = ব্যাংকে থাকা ক্যাশ ÷ মাসিক বার্ন**

মাসিক বার্ন মানে এই মাসের ফিক্সড খরচ থেকে এই মাসের মোট কন্ট্রিবিউশন বাদ দিলে যা থাকে। রাহিমের এই মাসের হিসাবে ফিক্সড খরচ ১১ হাজার ৫০০ টাকা, মোট কন্ট্রিবিউশন ৮ হাজার ৫০০ টাকা, তাই বার্ন দাঁড়ায় ৩ হাজার টাকা। ব্যাংকে আছে ২১ হাজার টাকা। রানওয়ে বের করতে ২১ হাজার টাকাকে ৩ হাজার টাকা দিয়ে ভাগ করুন, ফল দাঁড়ায় ৭ মাস।

এর মানে, আজ থেকে হিসাব একদম না বদলালে সাত মাস পর ব্যাংকে টাকা শেষ। বাস্তবে হিসাব প্রতি মাসেই একটু বদলায়, তাই রানওয়ে প্রতি মাসে নতুন করে বের করতে হয়, একবার হিসাব করে ভুলে থাকলে চলবে না।

করণীয় সোজা। রানওয়ে ৬ মাসের নিচে নামলে বা টানা কমতে থাকলে তিনটা রাস্তা খোলা থাকে, খরচ কমান, কন্ট্রিবিউশন বাড়ান ([ইউনিট ইকোনমিক্সের](/metrics/unit-economics) ব্রেক-ইভেন অংশ দেখুন), অথবা বাইরে থেকে টাকা আনার পরিকল্পনা এখনই শুরু করুন। সংখ্যাটা শূন্যের কাছে যাওয়ার অপেক্ষা করবেন না, তত দিনে সিদ্ধান্ত নেওয়ার সময় থাকে না।

একটা কথা মনে রাখা ভালো। বার্ন যদি ঋণাত্মক হয়, মানে কন্ট্রিবিউশন ফিক্সড খরচের চেয়ে বেশি, তাহলে ব্যবসা লাভ করছে, ব্যাংকে টাকা প্রতি মাসে বাড়ছে। তখন রানওয়ে কার্যত অসীম, তবু নম্বরটা প্রতি মাসে দেখে যান। হুট করে বদলে গেলে তখনই ধরা পড়বে, মাস শেষে অবাক হতে হবে না।

## কবে বসে করবেন

মাসের একটা নির্দিষ্ট দিন বেছে নিন, যেমন প্রতি মাসের ১ তারিখ বা ব্যাংক স্টেটমেন্ট হাতে আসার পরের দিন, আর প্রতি মাসে সেই একই দিনে বসুন। একই দিনে করলে এক মাসের সংখ্যা আরেক মাসের সঙ্গে সত্যিই মেলানো যায়, এলোমেলো দিনে করলে তুলনাটাই মিথ্যা হয়ে যায়।

সাপ্তাহিক অর্ডার আর খরচের হিসাব আগে থেকে টুকে রাখা থাকলে এই টেবিল ভরতে ৩০-৪৫ মিনিটের বেশি লাগার কথা না। প্রথমবার শেষ কয়েক মাসের অর্ডার আর ব্যাংক স্টেটমেন্ট ঘেঁটে বসাতে ঘণ্টাখানেক লাগতে পারে, তারপরের মাসগুলো অনেক দ্রুত হয়ে যায়।

## চেকলিস্ট

- এই মাসের ব্যাংক ব্যালেন্স, বিক্রি, কন্ট্রিবিউশন আর CAC লিখেছি
- গত মাসের সংখ্যার পাশে বসিয়ে ট্রেন্ড দেখেছি
- মাসিক বার্ন বের করেছি, ফিক্সড খরচ বিয়োগ কন্ট্রিবিউশন
- রানওয়ে বের করেছি, ব্যাংকে ক্যাশ ভাগ মাসিক বার্ন
- বিক্রি আর মুনাফাকে আলাদা সংখ্যা হিসেবে দেখেছি, এক করে ফেলিনি
- নিজের ব্যবসায় যা প্রযোজ্য না, সেই ঘরে জোর করে সংখ্যা না বসিয়ে "প্রযোজ্য নয়" লিখেছি
- সপ্তাহ বা দিনভিত্তিক অপারেশনাল সংখ্যার জন্য আলাদা ড্যাশবোর্ড ব্যবহার করছি

থাম্ব রুল: **রানওয়ে ৬ মাসের নিচে নামলে অপেক্ষা করবেন না, সেই মাসেই খরচ কমান বা টাকা আনার পরিকল্পনা শুরু করুন।**
