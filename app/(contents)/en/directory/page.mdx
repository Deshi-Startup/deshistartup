# Directory – Verified Bangladesh Startup Ecosystem List

> **TL;DR:** Inclusion is not an endorsement or a promise of funding. Check the public source and last-verification date on each entry. If a fee, cheque size or deadline is not stated, do not infer it. Re-check the organisation's own site before you act.

## How the Directory Is Maintained

Entries come from `data/directory/*.json`. A new organisation is checked against an official site or reliable public profile. If a fee, cheque size or deadline is not public, the field remains `Not publicly stated`. The target cadence is quarterly re-verification.
