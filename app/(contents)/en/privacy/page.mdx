# Privacy Policy

> **In short:** Reading guides requires no account. Editing with Google provides your name, email,
> profile image and a temporary identity token. Submitted text, images and your name enter the
> review process. Measurement tags may run through Google Tag Manager to help understand site use.

**Effective: 28 July 2026**

## Reading the site

Hosting and security services may process ordinary request data such as IP address, browser, time
and requested URL.

The site loads Google Tag Manager. Measurement tags configured inside it may send data such as page
views, device information, approximate location and referring page to Google. The application code
does not currently provide advertising or build its own reader profiles. Browser privacy and
tracking controls may limit this processing.

## Editing a page

Google sign-in provides a name, email, profile image and signed temporary ID token.

- The token stays in browser local storage and normally expires in about one hour.
- An unfinished local draft may stay in the same browser for up to 14 days.
- The server verifies the token on every request and keeps no separate login session.
- Submitted text, summary and name appear in a public GitHub pull request; the email does not.
- Account-based rate limits and mute/ban records may be used to prevent abuse.

## Contributing an image

Image bytes, type, dimensions, alt text, source/credit, page path and a hashed account identifier
are stored in a private quarantine bucket. Only the owner and authorized reviewers can view a
pending image.

- Approved images become part of the public media library and GitHub history.
- Rejected images are deleted immediately.
- Undecided pending images expire after seven days.
- Review checks privacy, copyright, personal information and necessary redaction before publication.

Do not submit another person's private information, confidential documents or sensitive
screenshots without permission.

## Retention and other services

Expired tokens and local drafts older than 14 days are removed when the browser next uses the
editor. Accepted contributions may remain in public GitHub history. Approved media may remain in
content history and caches.

Google, GitHub and Cloudflare process information under their own policies.

## Questions or removal requests

[Open a GitHub issue](https://github.com/Deshi-Startup/deshistartup/issues/new), but do not place
sensitive information in a public issue. A public contribution may not be fully removable after it
has been copied into git history, forks or caches.
