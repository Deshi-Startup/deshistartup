# Contact Deshi Startup

Have a question about something on the site, spotted a mistake, or want to help write? Send it through the form below. Deshi Startup is run by a small team and a handful of volunteer contributors, so a reply can take a few days. However, we do read every message.

## Where to write

Some things move faster when they go straight to the right place instead of the inbox.

- **A mistake in a guide:** [open an issue on GitHub](https://github.com/Deshi-Startup/deshistartup/issues/new?template=report-mistake.yml). The report stays with that page's history, where anyone can pick it up and fix it.
- **A security problem:** email **security@deshistartup.com**. The [security policy](https://github.com/Deshi-Startup/deshistartup/blob/main/SECURITY.md) says what to include.
- **Behaviour that breaks the code of conduct:** email **conduct@deshistartup.com**. Only the maintainers read that inbox.
- **You want to contribute:** start with the [How to contribute](/en/contribute) guide.
- **A short question for the community:** ask it in the [Facebook community](https://www.facebook.com/groups/deshistartup/).

## Email us

To write from your own mail app, the address is **[hello@deshistartup.com](mailto:hello@deshistartup.com)**. Messages from the form above land in the same inbox. What happens to what you send is set out in the [privacy policy](/en/privacy).
