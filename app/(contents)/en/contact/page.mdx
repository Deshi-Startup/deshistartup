# Contact Deshi Startup

Have a question about something on the site, spotted a mistake, or want to help write? Send it through the form below. Deshi Startup is run by a small team and a handful of volunteer contributors, so a reply can take a few days. We do read every message.

## Where to write about what

Some things reach the right person faster outside the inbox.

- **A mistake in a guide.** [Report it on GitHub](https://github.com/Deshi-Startup/deshistartup/issues/new?template=report-mistake.yml). It stays with that page's history, where anyone can help fix it.
- **A security problem in the site or the contribution flow.** Email **security@deshistartup.com**. The [security policy](https://github.com/Deshi-Startup/deshistartup/blob/main/SECURITY.md) says what to include.
- **Behaviour that breaks the code of conduct.** Email **conduct@deshistartup.com**. Only the maintainers read that address.
- **You want to write, translate or edit.** Start at [Contribute](/en/contribute).
- **A short question you would rather ask out loud.** Ask in the [Discord community](https://discord.gg/Wsgn3CaFyD).

## Email us directly

If you would rather write from your own mail app, the address is **[hello@deshistartup.com](mailto:hello@deshistartup.com)**. Messages from the form above reach the same inbox. What happens to what you send is described in the [privacy policy](/en/privacy).
